# Penrose Nocturne (macOS)

[HTML 版](../web/quasicrystal-wallpaper.html) の五重ペンタグリッドから生成する菱形ペンローズ模様を、macOS のデスクトップ背景として描画する Swift / AppKit アプリです。macOS 13 以降と Xcode の Command Line Tools が必要です。

```sh
./scripts/build-app.sh penrose
open "dist/Penrose Nocturne.app"
```

Swift Package として直接起動する場合は `swift run PenroseWallpaper` も使えます。アプリは Dock に表示されず、メニューバーの「◇」から一時停止・終了できます。各ディスプレイにボーダーレスのデスクトップレベルのウィンドウを設置し、Space の切り替えやディスプレイ構成の変更にも対応します。ウィンドウはクリックを受け取らず、デスクトップのアイコンや通常のウィンドウの操作を妨げません。マウス座標を監視し、ポインタ直下のタイルが淡く光ります。フリップはありません。周囲には控えめな光の波紋が広がります。HTML 版と同じ HSL 色指定を基調に、全タイルの頂点が共有された変形場でゆっくり動き、暗い青緑の色相・明暗にも少し速めの光の波が流れます。金色への変化はタイルごとに異なる約7〜23秒の時計と位相・確率で起こり、全体が同時に切り替わることはありません。各タイルの色のゆらぎと金色の光沢もそれぞれ異なる速さ・位相で変化します。

これはシステムの壁紙設定を変更しません。終了すると元の壁紙に戻ります。ログイン時に起動したい場合は、macOS の「システム設定 → 一般 → ログイン項目」に生成されたアプリを登録してください。未署名のローカルビルドです。
