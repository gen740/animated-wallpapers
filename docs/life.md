# Life — Matte Gold

黒と落ち着いた金色の、Conway のライフゲームを描く macOS デスクトップアプリです。起動時にランダムな生死パターンを生成し、約0.24秒ごとに世代を進めます。停止状態やほぼ全滅になったときは再生成します。

```sh
./scripts/build-app.sh life
open "dist/Life Matte Gold.app"
```

画面上のどこをクリックしても、その座標にある背景側のマスの生死を反転します。通常のアプリのウィンドウやデスクトップアイコンをクリックしても裏側の盤面が変化します。壁紙のウィンドウ自体はクリックを透過するため、通常の操作を妨げません。短い回転アニメーションの後に次の世代へ進みます。macOS のグローバルマウスイベント監視を使用します。環境によってクリックが監視されない場合は、システム設定の「プライバシーとセキュリティ → 入力監視」でこのアプリへの許可を確認してください。メニューバーの「▦」から一時停止、ランダム再生成、終了ができます。各ディスプレイに独立した盤面を表示します。

macOS 13 以降、Xcode Command Line Tools が必要です。Penrose Nocturne と同時に使う場合はデスクトップウィンドウが重なるため、どちらか一方を終了してください。アプリはシステムの壁紙設定を変更しません。
